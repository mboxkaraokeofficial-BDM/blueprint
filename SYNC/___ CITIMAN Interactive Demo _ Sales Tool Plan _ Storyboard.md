## Overview

## 🗂️ Tool Plan — 4 หน้าจอหลัก

### 1. 📊 Dashboard

วัตถุประสงค์: แสดง Big Picture — ผู้บริหารเห็นภาพรวมทันที

Key Message: "ผู้บริหารเห็นทุกอย่างใน 1 หน้าจอ — ไม่ต้องรอรายงาน"

### 2. 📝 ยื่นคำร้อง + MODA Animation

วัตถุประสงค์: แสดงขั้นตอน Citizen ยื่นเรื่อง → AI จัดสรรให้อัตโนมัติ

ฟอร์ม Input:

- ชื่อ-นามสกุล / เบอร์โทร
- ประเภทคำร้อง (ถนน / ไฟฟ้า / น้ำ / ขยะ / สะพาน)
- พื้นที่/หมู่บ้าน
- รายละเอียด (pre-filled ด้วยตัวอย่างจริง)
MODA Animation Flow (4 Steps × 1.3 วินาที/step):

Success State: REF Box แสดง REF-2569-1248 พร้อมปุ่ม "ติดตามสถานะ →" ลิงค์ไป Citizen Portal

Key Message: "MODA วิเคราะห์และจัดสรรใน <1 นาที — ไม่ต้องมีเจ้าหน้าที่คอยรับเรื่อง"

### 3. ⏰ SLA Monitor

วัตถุประสงค์: แสดงให้เห็นว่าระบบ Track กำหนดเวลาแบบ Real-time

Alert Banner: แจ้งเตือน 14 รายการเกินกำหนด + 28 รายการใกล้ครบ

Filter Tabs (Clickable):

- ทั้งหมด (87)
- ⚠ เกินกำหนด (14)
- 🔔 ใกล้ครบกำหนด (28)
- ✅ ปกติ (45)
ตาราง: เลขที่ / ประเภท / แผนก / ผู้รับผิดชอบ / SLA / สถานะ (chip สี)

Key Message: "ผู้บริหาร Track ได้เองว่างานไหนช้า ใครรับผิดชอบ — ไม่ต้องตาม"

### 4. 👥 Citizen Portal

วัตถุประสงค์: แสดงฝั่งประชาชน — ตรวจสอบสถานะด้วยตัวเอง

Hero Search Box: กรอก REF Number → แสดง Timeline

Timeline 4 Steps:

1. ✅ รับเรื่องเรียบร้อย
1. ✅ MODA วิเคราะห์และจัดสรรงาน
1. 🔵 กำลังดำเนินการ (active)
1. ⚪ เสร็จสิ้น (pending)
Key Message: "ประชาชนตรวจสอบได้ตลอด 24 ชม. ไม่ต้องโทรถาม — ลดภาระ Call Center"

## 📌 Tips สำหรับทีมขาย

- ใช้ Mobile หรือ Tablet ได้ — Demo ตอบสนองหน้าจอทุกขนาด
- ล็อกอิน ก่อนเจอ Prospect — หน้าต้องการ work_auth session
- ไม่ต้อง Internet เร็วมาก — ไฟล์เล็ก โหลดไว
- MODA Animation เล่นครั้งเดียว — ถ้าจะ Replay ให้กด "ยกเลิก" แล้วกด Submit ใหม่
- Citizen Portal — พิมพ์ REF อะไรก็ได้ ระบบจะแสดง Timeline ตัวอย่างให้เสมอ
